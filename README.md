# Márcio Silva | Personal Trainer

Página de apresentação profissional, com atendimento presencial em Juiz de Fora e consultoria online.

## Arquivos

- `index.html`: página principal.
- `marcio-bokeh-site.webp`: fotografia da apresentação e do perfil.
- `monograma-ms-oficial.png`: logo oficial usada no cabeçalho e rodapé.
- `social-preview.jpg`: prévia usada ao compartilhar o link.
- `favicon.png` e `apple-touch-icon.png`: ícones para navegadores e dispositivos móveis.

## Como visualizar

Abra `index.html` no navegador. Deixe todos os arquivos na mesma pasta.

## Publicação

Os metadados de compartilhamento apontam para o endereço existente no GitHub Pages.
Envie os arquivos juntos para a raiz do repositório da página quando aprovar a revisão.
O endereço do repositório foi preservado.
Não há integração com o aplicativo de consultoria.
